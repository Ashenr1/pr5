## 📋 Описание проекта

Проект представляет собой клиент-серверную систему управления лицензиями (**ManagerLicense**), реализованную на языке **C# (.NET 8)** с использованием сетевого транспортного протокола **TCP**.

Работа полностью удовлетворяет всем базовым требованиям и дополнительному требованию на оценку **«Хорошо»**.

---

### 🌟 Реализованный функционал:

#### 1. Сервер лицензий:
1. **Генерация уникального кода:** при обращении клиента генерируется криптостойкий уникальный 10-значный токен (например, `swZXg0vr0i`), служащий идентификатором клиента.
2. **Контроль доступных мест:** проверка количества подключений. При превышении лимита (по умолчанию `2`) сервер отклоняет новые подключения с сообщением `ERROR: No available license slots`.
3. **Мониторинг клиентов (`/status`):** отображает количество подключенных клиентов, их уникальные токены, IP-адреса, порты, дату и время подключения (`HH:mm:ss dd.MM`), продолжительность подключения в секундах и остаток времени жизни токена.
4. **Таймаут действия токена:** по истечении времени $N$ (по умолчанию `120` сек) сервер отключает клиента для обновления уникального кода.
5. **Отключение клиентов по команде:** административная команда `/disconnect <token>` (или `/disconnect all`) для немедленного отключения клиента.
6. **Настройка при запуске:** запрос IP-адреса, порта, максимального числа клиентов и времени жизни токена (нажатие Enter выбирает рекомендуемые значения по умолчанию). Команда `/config` для изменения параметров на лету.

#### 2. Клиент лицензий:
1. **Получение уникального кода:** отправка запроса на сервер по команде `/connect` и немедленное получение выданного уникального токена.
2. **Первоначальная настройка:** запрос IP-адреса и порта сервера при старте (Enter — значения по умолчанию `127.0.0.1:5000`).
3. **Отображение информации (`/status`):** вывод текущего токена, даты и времени подключения и продолжительности сессии (в секундах).
4. **Фоновый Heartbeat:** периодическая проверка связи с сервером (раз в 3 секунды). При принудительном отключении со стороны сервера клиент сразу выводит сообщение: `The client is disconnected from the server`.
5. **Обновление токена (`/renew`):** возможность запросить новый токен до истечения времени старого.

#### 3. Функционал на оценку «Хорошо» (Чёрный список):
- Добавление клиентов/IP в чёрный список: команда `/block <IP или токен>`.
- Удаление из чёрного списка: команда `/unblock <IP>`.
- Просмотр чёрного списка: команда `/blacklist`.
- При попытке подключения клиента с заблокированного IP сервер возвращает ошибку `ERROR: Client IP is in the blacklist` и разрывает соединение.

## 🚀 Инструкция по запуску

### 1. Запуск сервера:
Запустите файл `run_server.bat` или выполните:
```bash
dotnet run --project Server\Server.csproj
```
Нажмите **Enter** 4 раза для применения настроек по умолчанию (`127.0.0.1:5000`, 2 клиента, 120 сек).

### 2. Запуск клиента:
В отдельном окне запустите `run_client.bat` или выполните:
```bash
dotnet run --project Client\Client.csproj
```
1. Нажмите **Enter** 2 раза (IP: `127.0.0.1`, порт: `5000`).
2. Введите `/connect` — подключение произойдёт автоматически, клиент получит токен.
3. Введите `/status` — отобразится токен, время и длительность сессии.

## ⌨️ Список команд

### Сервер:
| Команда                 | Описание                                                             |
| ----------------------- | -------------------------------------------------------------------- |
| `/status`               | Показать всех подключенных клиентов (токен, IP, время, длительность) |
| `/disconnect <token>`   | Отключить конкретного клиента по токену                              |
| `/disconnect all`       | Отключить всех клиентов                                              |
| `/block <ip или token>` | Добавить в чёрный список (Оценка «Хорошо»)                           |
| `/unblock <ip>`         | Удалить из чёрного списка (Оценка «Хорошо»)                          |
| `/blacklist`            | Показать список заблокированных IP (Оценка «Хорошо»)                 |
| `/config`               | Изменить настройки сервера                                           |
| `/clear`                | Очистить консоль                                                     |
| `/help`                 | Список команд                                                        |
| `/exit`                 | Остановить сервер                                                    |

### Клиент:
| Команда       | Описание                                         |
| ------------- | ------------------------------------------------ |
| `/connect`    | Подключиться к серверу и получить токен лицензии |
| `/status`     | Вывести токен, время подключения и длительность  |
| `/renew`      | Обновить/продлить токен досрочно                 |
| `/disconnect` | Отключиться от сервера                           |
| `/config`     | Изменить IP и порт сервера                       |
| `/clear`      | Очистить консоль                                 |
| `/help`       | Список команд                                    |
| `/exit`       | Выйти из программы                               |
